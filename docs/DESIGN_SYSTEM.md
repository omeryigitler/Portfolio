# Portfolio interaction contract

Locked direction for the current portfolio iteration.

- The portfolio is divided into six explicit chapter pages: 01 / Intro, 02 / Selected Work, 03 / Transition, 04 / About, 05 / Capabilities, 06 / Contact.
- Each chapter is visually framed as its own warm-white page over the separate outer visual world. Consistent width, corner radius, shadow and spacing define the page boundaries.
- A collapsible chapter navigator lives on the left edge. The collapsed state shows the current chapter number + six progress ticks; opening it reveals all six destinations. It replaces the old top navigation.
- Acid yellow is a signal only; text stays black. The hero uses a scroll-driven marker stroke through WORTH, not a long underline.
- Hero: automatic intro, two-line desktop headline, no scroll pin.
- Work: one chapter page with an internal sticky project theatre, real project media, custom project cursor and shared-media preview.
- Transition: one chapter page with the SCREEN aperture and white-sheet lift-away sequence.
- About stays calm and fills its own chapter page.
- Capabilities fills its own chapter page and keeps the editorial section label + interactive nodes.
- Contact and footer remain one unified final chapter page. Never render them as separate stacked sections that can leave an orphaned CTA, utility row or wordmark in the viewport.
- The final chapter contains 06 / CONTACT, HAVE AN IDEA?, MAKE IT REAL + arrow, copyright, Instagram, GitHub and the oversized omeryigitler wordmark in one composition.
- Chapter labels always use number first: 01 / INTRO, 02 / SELECTED WORK, 03 / TRANSITION, 04 / ABOUT, 05 / CAPABILITIES, 06 / CONTACT.
- No fake Lab, no filler slogans, no unsolicited navigation redesigns.
