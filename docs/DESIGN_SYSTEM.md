# Portfolio interaction contract

Locked direction for the current portfolio iteration.

- The portfolio is divided into six explicit chapter pages: 01 / Intro, 02 / Selected Work, 03 / Transition, 04 / About, 05 / Capabilities, 06 / Contact.
- Each chapter is visually framed as its own warm-white page over the separate outer visual world. Consistent width, corner radius, shadow and spacing define the page boundaries.
- A collapsible chapter navigator lives on the left edge. The collapsed state is a compact launcher showing only the active chapter number + directional arrow. It opens by click into a separate horizontal index panel; it must not morph from the old vertical progress-rail design.
- The expanded chapter navigator includes a top-left ↖ close/back control. Its arrow shifts to the right on hover. Menu item number + label shift slightly right on hover. Active destinations use a restrained acid-yellow line signal, not yellow text or colored pills.
- The chapter navigator is hidden while a project preview or contact form is open, and it fades out completely on the unnumbered final footer sheet.
- Acid yellow is a signal only; text stays black. The hero promise is lowercase editorial typography; the only yellow hero accent is the final punctuation mark.
- Hero: automatic intro, fixed two-line desktop headline: `digital experiences` / `worth remembering.`. No scroll pin and no marker stroke through WORTH.
- Work: one chapter page with an internal sticky project theatre, real project media, custom project cursor and shared-media preview. Project screenshots remain fully colored; the surrounding portfolio UI stays neutral. The outer environment may echo project imagery only in heavily desaturated form.
- Transition: one chapter page with a single black SCREEN word that becomes a monochrome aperture, then the white sheet lifts away. The transition explicitly communicates moving from WORK to APPROACH; no blue/pastel SCREEN treatment.
- About stays calm and fills its own chapter page.
- Capabilities fills its own chapter page and keeps the editorial section label + interactive nodes.
- Contact is its own 06 / CONTACT chapter page containing HAVE AN IDEA? and MAKE IT REAL. The circular ↗ control sits below the headline, not beside it. Clicking the CTA opens a full-sheet project request form.
- The project request form asks for name, visitor email, project type, timing and project description. Scroll is locked while the form is open. Delivery remains unconnected until the real portfolio email address is supplied.
- Footer is a separate unnumbered final sheet after Contact, containing copyright, Email trigger, Instagram, GitHub and the oversized omeryigitler wordmark. No chapter number/navigation appears over the footer.
- Chapter labels always use number first: 01 / INTRO, 02 / SELECTED WORK, 03 / TRANSITION, 04 / ABOUT, 05 / CAPABILITIES, 06 / CONTACT.
- No fake Lab, no filler slogans, no unsolicited navigation redesigns.
