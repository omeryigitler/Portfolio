# Portfolio interaction contract

Locked direction for the current portfolio iteration.

- One continuous warm-white editorial canvas sits over a separate outer visual world. Hero and Work must never use different canvas widths.
- Acid yellow is a signal only; text stays black. The hero uses a scroll-driven marker stroke through WORTH, not a long underline.
- Navigation has no logo/monogram. It is right-aligned: Work / About / Contact. It is visible at the top, hides while scrolling down, returns when scrolling up, and always hides while a project preview is open.
- Hero: automatic intro, two-line desktop headline, no scroll pin, no second nested white frame.
- Work: sticky theatre, real project media, custom project cursor, shared-media preview.
- Transition: one SCREEN word, black to aperture, then the white sheet lifts away.
- About and Contact stay calm.
- Capabilities keeps the editorial section label + interactive nodes.
- Footer keeps socials + oversized omeryigitler wordmark.
- No fake Lab, no filler slogans, no unsolicited navigation redesigns.
